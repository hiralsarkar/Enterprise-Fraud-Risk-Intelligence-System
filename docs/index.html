    How it works

    Five steps from raw payment to audit trail

    1. STEP 1

      Ingest

      Join Vesta's transaction table (55 columns) with the identity table (41 columns).

      590,540 rows
    2. STEP 2

      Engineer

      Add ten bank-style signals: spend z-score per card, email and address mismatch, night-time, velocity.

      63 features
    3. STEP 3

      Classify

      A depth-8 decision tree is the explainable champion. XGBoost with 300 trees is the challenger.

      2 models
    4. STEP 4

      Triage

      SHAP names the top factors for each flagged payment. An LLM turns them into a SAR-style note.

      ~15 min saved per case
    5. STEP 5

      Monitor

      KS and Gini on a time-ordered holdout, then PSI to catch population drift after launch.

      PSI 0.001

    Drift check

    PSI compares the score distribution the model was trained on with what it sees later. Under 0.10 is stable. Over 0.25 means the model goes back for review.

    Run it

    Reproduce it on your machine

    You need Python and the Kaggle IEEE-CIS files. The OpenRouter key is optional: without it the triage step falls back to a template note.

    # 1. Clone and install
git clone https://github.com/hiralsarkar/Enterprise-Fraud-Risk-Intelligence-System.git
cd Enterprise-Fraud-Risk-Intelligence-System/fraud_classifier
pip install -r requirements.txt

# 2. Put the Kaggle CSVs in ./data/ieee-fraud-detection/
kaggle competitions download -c ieee-fraud-detection

# 3. Features, then models, then triage and drift
python notebooks/01_eda_feature_engineering.py
python notebooks/02_model_training_validation.py
export OPENROUTER_API_KEY="your-key-here"   # optional
python notebooks/03_risk_pipeline_llm_triage.py

# 4. Open the analyst console
python -m http.server -d ../console 8000

    Known limits

    • The holdout was also used for early stopping, so the reported metrics lean optimistic.
    • Probabilities are not calibrated yet. Treat the bands as rankings until they are.
    • This is a portfolio build on public data. It has not been through an independent validation.
